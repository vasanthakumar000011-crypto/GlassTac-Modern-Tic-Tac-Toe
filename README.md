# 🎮 Tic Tac Toe – Glass UI Edition

A modern, animated Tic Tac Toe game built with **Python and Pygame**, focusing on clean UI/UX, smooth animations, and intelligent gameplay.

---

## ✨ Features

- 🧑‍🤝‍🧑 Human vs Human mode  
- 🤖 Human vs AI mode  
  - Easy difficulty  
  - Hard (Unbeatable) AI using Minimax  
- 🎨 Glassmorphism-inspired transparent UI  
- ❌ ⭕ Animated emoji symbols  
- 🌟 Winning glow line & screen shake effect  
- 💥 Particle burst animation on moves  
- 🤝 Clear “Match Draw” indication  
- 🔄 Restart option  

---

## 🛠️ Technologies Used

- **Python 3**
- **Pygame**
- Game logic & AI (Minimax Algorithm)
- UI/UX animation techniques
